# Website Đình — Vietnamese Fine Coffee

Website tĩnh (một file `index.html`), deploy miễn phí trên Vercel từ repo này.

## Cấu trúc
- `index.html` — toàn bộ trang (CSS/JS viết inline trong file)
- `images/logo.jpg` — logo Đình
- `images/hero-roastery.jpg` — ảnh hero / giới thiệu xưởng rang
- `images/product-cau-dat.jpg`, `images/product-dak-lak.jpg`, `images/product-espresso.jpg` — ảnh sản phẩm

## ⚠️ Dữ liệu MẪU cần thay khi có thông tin thật
1. **Tên + giá sản phẩm** trong `index.html` (tìm `280.000đ`, `250.000đ`, `220.000đ`) — hiện là giá mẫu.
2. **Ảnh túi cà phê** trong `images/product-*.jpg` — hiện là ảnh minh họa AI, thay bằng ảnh chụp túi thật (giữ nguyên tên file là web tự cập nhật).
3. **Ảnh hero** `images/hero-roastery.jpg` — có thể thay bằng ảnh xưởng rang thật.

## Deploy lên Vercel (miễn phí)
1. Vào vercel.com → đăng nhập bằng GitHub → "Add New Project" → chọn repo `Dinh---Website` → Deploy.
2. Được link dạng `dinh-website.vercel.app`. Sau này mua tên miền trên Namecheap rồi trỏ về Vercel theo hướng dẫn của Vercel.
